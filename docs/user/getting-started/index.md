Install NOVA Tasarım first, then start a document.

1. [Install NOVA Tasarım](install.md) on Windows 11, macOS or Linux.
2. Open NOVA Tasarım. The start screen has three buttons: **New file**, **Open** and **Open sample magazine**.
3. Click **Open sample magazine** to see a finished layout, or follow [Create a new document](../guides/create-a-document.md) to begin your own.

NOVA Tasarım also runs in a web browser. See [Which systems does NOVA Tasarım run on?](../faq/supported-systems.md).
